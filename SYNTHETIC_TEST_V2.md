# Synthetic discovery v2

Запуск полного протокола (последовательно, одна GPU):

```bash
bash scripts/run_synthetic_test_v2.sh --output runs/synthetic_v2
```

Скрипт использует прежний `uv.lock` и дополнительно устанавливает
`parasail==1.3.4` (также указан в `requirements-v2.txt`). Нужен доступ к PyPI.
Модель: `data/model`, checkpoint: `runs/baseline/best.pt`; пути можно переопределить.
Frozen NT всегда загружается из исходной модели, проекция — из checkpoint.
Старые скрипты и результаты не меняются. Каталог результата обязан быть новым.

Для проверки только классического канала и validation:

```bash
bash scripts/run_synthetic_test_v2.sh --channels anchors --validation-only --output runs/v2_validation
```

По умолчанию: фон seed=45, validation seed=44 (4 независимых семейства,
30 копий длиной 200/300/400/500, x=0/0.5), затем финальный seed=43
(150 копий по 300 bp, минимальный промежуток 800 bp как в v1, x=0/0.5/1/1.5/2). Параметры фиксируются в
`fixed_parameters.json` до генерации финального теста. Не следует повторно
подбирать их по финальным результатам. `--genome-size` предназначен для
технических проверок; изменение размера означает другой эксперимент.

Окна 200/400 bp с шагом 50; до 64 неперекрывающихся соседей на окно.
Канонические 9-меры агрегируются по точной диагонали и ориентации в
перекрывающихся пространственных блоках 200 bp; требуется две разные позиции
с охватом ≥40 bp. Частые слова не отбрасываются, кандидаты не обрезаются.
Оба направления локального выравнивания проверяются Parasail, score +2/-1,
gap-open 5, gap-extend 2. Расширение кандидатов 200 bp с каждой стороны.
Порог строгий: score > квантиль (максимум исключает все наблюдавшиеся фоновые
выравнивания). Минимальная длина — минимум из двух длин без gap.

Сетка 3×4 отдельно для каждого канала и union. Выбор по среднему pair-F1
при locus precision ≥0.9 на **каждом** уровне validation, оценка при IoU ≥0.5.
При провале ограничения выбирается максимальный средний locus-F1;
`precision_constraint_met=false` явно фиксирует провал. При равенстве выбирается
более строгий score, затем длина. Итоговые метрики сохраняются при IoU 0.2 и 0.5.
Best-family F1 усредняется по истинным семействам, каждому выбирается лучший
предсказанный кластер. `merged_families` считает предсказанные группы,
объединившие несколько истинных семейств.

Дубли объединяются только при взаимном покрытии ≥70%, причём все интервалы
в группе обязаны удовлетворять условию попарно. Представитель — медианные
границы. Самосвязи и связи пересекающихся локусов запрещены. Граф очищается
итеративно до минимальной степени 2, сохраняются компоненты ≥3 вершин.
**Ограничение:** единственный ошибочный мост между плотными группами сохраняется
и объединяет их. Контрпример закреплён тестом; метрика слияний выявляет ошибку.

Артефакты каждого генома: FASTA, окна, векторы, кандидаты с источниками,
все выравнивания с CIGAR/ориентацией/координатами, принятые выравнивания,
граф и локусы. `candidate_increment.json` считает правильные уникальные пары
истинных локусов, добавленные каждым представлением сверх anchors **до
выравнивания** (перекрытие ≥20% истинного локуса, одинаковое семейство).
Это диагностическая оценка, не вход поиска. Вырезанные копии validation дают
отдельные распределения положительных/отрицательных пар и точность ближайшего
соседа; диагностические векторы и пары сохранены отдельно. Они никогда не
передаются в поиск геномных кандидатов.

`metrics.tsv`/`metrics.json` сравнивают каналы и union; `validation_grid.json`
содержит всю сетку, `manifest.json` — параметры, версии и хеши, `progress.log` —
прогресс и скорость. Успех x=0 требует precision/recall/best-family F1 ≥0.9.
Полный тест и кривая деградации должны быть получены запуском пользователя;
успех при больших x не предполагается заранее.

При недоступном Parasail можно явно выполнить диагностический запуск с точным
скалярным C backend (нужен GCC, компиляция локальная, без скачивания):

```bash
.venv/bin/python -u -m src.synthetic_benchmark_v2 --channels anchors \
  --alignment-backend reference --validation-only --output runs/v2_reference
```

Score и штрафы те же; backend отмечается в manifest и каждом выравнивании.
Этот запуск не проверяет SIMD Parasail. Нативный backend проверяется независимым
Python DP на случайных строках, gap-cost и координатами обратного комплемента.
