# Поиск семейств через согласие трёх копий и частотный профиль

Метод реализован в `src/triplet_seeds.py` и `src/profile_discovery.py`.
Он предназначен для дисперсных повторов с заменами, без инделов. Предок,
истинные координаты и число семейств не передаются в поиск. Это классический
метод; Transformer и обучение NT для него не нужны.

1. Индекс канонических 9-меров предлагает тройки независимых участков с общей
   опорой. Контексты ориентируются по каноническому слову, шаг выравнивания
   допускает только замены. Из каждого частого слова берутся до 32 равномерно
   распределённых по геному вхождений; настоящая численность семейств неизвестна.
2. Согласие трёх последовательностей оценивается относительно IID-фона по
   распределению колонок «все равны / два равны / все различаются». Общие девять
   опорных оснований исключены из score. Выбирается лучший участок вокруг
   опоры, минимум 100 bp, контекст до 300 bp в каждую сторону.
3. Тройка задаёт начальный профиль. Полный геном сканируется в обеих
   ориентациях. Каждый профиль также сканирует отдельный фон seed=45;
   порог — максимум фонового scan-score +2 nat, с нижней границей 0.
4. Для запуска расширения нужны ещё ≥3 независимых вхождения сверх исходной
   тройки и ≥6 найденных локусов всего. Профиль уточняется по частотам оснований,
   границы — по информативности колонок. Выполняются пять итераций.
5. До 100 новых профильных гипотез проверяются последовательно. Опоры уже
   найденного семейства пропускаются; повторные профили одного набора локусов
   не создают дополнительные семьи. Число истинных семейств не используется.

Поиск оснований тройки написан на C и компилируется локально GCC в `/tmp`.
Профильный scan использует NumPy/SciPy. CUDA и Parasail этому методу не нужны.

Запуск на одном контиге с независимым фоном:

```bash
OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 .venv/bin/python -m src.discover_profiles \
  --fasta genome.fa --background independent_background.fa --output runs/my_profiles
```

Результаты: `loci.bed`, `loci.jsonl`, исходные опоры `seeds.jsonl`, история
профилей с матрицами log-odds и координатами каждого scan, manifest и журнал.
Все координаты нулевые, полуоткрытые; ориентация явно указана.

## Протокол проверки

```bash
bash scripts/run_synthetic_profiles.sh --phase validation --output runs/profile_validation
bash scripts/run_synthetic_profiles.sh --phase final \
  --validation runs/profile_validation --output runs/profile_final
.venv/bin/python -m scripts.verify_profile_benchmark \
  --validation runs/profile_validation --final runs/profile_final
```

Validation: seed=44, 500 000 bp, четыре семейства по 30 копий длиной
200/300/400/500 bp, x=0 и 0.5. Отдельный отрицательный контроль seed=49
не содержит вставок. Seed=45 используется исключительно для калибровки.
Параметры и хеши исходников замораживаются до финального теста. Финальная
фаза запрещена при провале validation, изменении исходников/параметров или
повторном использовании финального теста с тем же validation-каталогом.

Final: seed=43, 500 000 bp, 150 копий длиной 300 bp; x=0/0.5/1/1.5/2.
Ровно `round((x/2)*L)` событий замены на копию, повторные попадания разрешены.
Фон, положения и ориентации сохраняются между уровнями. Поиск каждого уровня
начинается заново, профили между уровнями не переносятся.

Проверяющий скрипт заново вычисляет метрики по сохранённым координатам,
сверяет финальные входы с исходным генератором, проверяет неизменность исходников,
отрицательный контроль и precision/recall/family F1 ≥0.9 вплоть до x=1.5
при IoU ≥0.2 и ≥0.5. Он не запускает поиск повторно.

## Ограничения

Доказательство на синтетике с равномерным IID-фоном не означает установленную
точность на настоящем геноме. Инделы, составной фон, низкая сложность,
вложенные повторы и семейства с менее чем шестью доступными копиями пока
не проверены. При x=2 успех не предполагается. Улучшение NT этим результатом
не заявляется: рабочий канал использует согласие последовательностей.

Старый v2 Smith–Waterman-протокол и все его диагностические результаты оставлены
отдельно: `SYNTHETIC_TEST_V2.md`. Переход к многокопийному профилю вызван
измеренным провалом парного поиска при больших x.
